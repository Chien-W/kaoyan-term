# kaoyan-term

专门为工位与极客打造的 2027 考研英语终端敲词与听写工具。

## 特性

- **大纲权威词库**：完整内置教育部考研英语大纲 6,357 核心词汇，涵盖考研真题熟词生义、词性、音标与高频真题短语搭配。
- **键盘肌肉记忆**：终端直接敲词盲打拼写，按键逐字校对。
- **耳机真人发音**：单词出现或拼写完成时自动在耳机播放真人发音，支持按 `[空格]` 重播。
- **听力默写模式**：全盲拼写，听音辩词。
- **单元测试伪装模式**：按 `Ctrl+S` 一键切换伪装，屏幕输出伪装为 `go test` 单元测试日志流，隐蔽性极高。
- **秒级老板键**：按 `Esc` 或 `Ctrl+C` 立即清屏退出，返回原始终端命令行。
- **单二进制零依赖**：词库通过 Go 1.16+ `//go:embed` 直接内嵌进可执行文件，无需安装外部运行环境或依赖。

## 安装

```bash
cd kaoyan-term
go build -o ~/workspace/go/bin/kaoyan main.go
```

## 快速使用

在任何终端中直接执行：

```bash
# 1. 默认打字背诵模式（从断点续背）
kaoyan

# 2. 伪装模式（输出模拟为 go test 单元测试输出）
kaoyan -stealth

# 3. 听力默写模式（遮蔽英文拼写）
kaoyan -dict

# 4. 错题本专项突破
kaoyan -wrong

# 5. 从指定单词序号开始
kaoyan -start 100
```

## 快捷键

- `[字母键]`：拼写单词
- `[空格]`：重播当前单词真人发音
- `[Tab]` 或 `[?]`：提示下一个字母
- `[Backspace]`：回退删除
- `[Ctrl+S]`：即时切换常规终端模式 / go test 单元测试伪装模式
- `[Ctrl+D]`：即时切换常规拼写 / 听力默写模式
- `[Esc]` 或 `[Ctrl+C]`：老板键，瞬间清屏退出
